# 서울시 강남구 재가노인복지기관 소식 문체 가이드 (초안)

홈페이지 "소식"에 올라가는 모든 글은 이 기준에 맞춰 다듬습니다.
직원은 편하게 쓰고, Claude가 이 기준으로 다듬은 뒤 담당자가 확인해 공개합니다.

## 1. 기본 원칙
- 기관을 대표하는 공식 글입니다. 정중하고 따뜻하되, 과장하지 않습니다.
- 사실(날짜, 장소, 인원, 기관명, 금액)은 원문 그대로 둡니다. 다듬을 때 바꾸지 않습니다.
- 원문에 없는 내용은 지어내지 않습니다.

## 2. 문장
| 항목 | 기준 | 예시 |
|---|---|---|
| 문장 끝 | 합쇼체 "~했습니다 / ~합니다" | 진행했습니다, 안내드립니다 |
| 문장 길이 | 한 문장에 한 가지 내용, 40자 안팎 | |
| 문단 | 2~3문장마다 줄 바꿈 | |
| 이모티콘·느낌표 | 쓰지 않음 (느낌표는 감사 인사에만 1회 허용) | |
| 줄임말·유행어 | 쓰지 않음 | 넘 좋았어요 → 매우 뜻깊은 시간이었습니다 |

## 4. 글 구성
### 활동 소식
1. 첫 문단: 언제, 어디서, 무엇을 했는지 한두 문장
2. 본문: 활동 내용과 어르신·참여자의 모습
3. 마무리: 함께한 기관·자원봉사자에 대한 감사 인사 한 문장

### 공지
1. 첫 문장: 무엇을 알리는지
2. 본문: 대상, 기간, 방법을 항목으로 정리
3. 마무리: 문의처 (02-573-7943)

### 언론 보도
1. 언론사 이름과 보도 날짜
2. 보도 내용 요약 두세 문장
3. 원문 기사 링크

## 5. 개인정보 (공개 금지)
다음 내용이 원문에 있으면 지우고 "점검 필요"로 표시합니다.
- 어르신 성함, 나이, 주소, 연락처, 건강 상태, 가정 형편 등 개인을 알아볼 수 있는 내용
- 직원·자원봉사자의 개인 연락처
- 후원자 개인 성함 (본인 동의가 확인된 경우만 공개)

단, 업무관리 "함께한 곳" 칸과 제목에 적은 단체명·개인 이름은 작성자가 공개하려고 넣은 것이므로 지우거나 가리지 않습니다.
- 사진: 초상권 동의를 받은 사진만 사용
