# 웹 접근성 자체 점검 결과

- 대상: www.gnjaega.or.kr 전체 11개 페이지 (첫 화면, 기관 소개, 사업 안내, 후원, 자원봉사, 현장실습, 소식, 소식 상세, 소리함, 인권·윤리, 개인정보처리방침)
- 점검일: 2026년 11월 2일
- 기준: 한국형 웹 콘텐츠 접근성 지침(KWCAG) 2.2, 33개 검사 항목
- 방법
  - 자동 점검: axe-core 4.10 (WCAG 2.2 AA 규칙), W3C HTML 검사기
  - 직접 점검: 키보드만으로 사용, 초점 표시, 글자와 배경 명도 대비, 화면 폭 320px에서 '아주 크게' 글자로 보기, 제목·링크·표 구조 확인

## 점검 중 고친 것

| 내용 | 조치 |
|---|---|
| 첫 화면 작은 제목(OUR WORK 등) 글자색 대비 4.32:1 (기준 4.5:1 미만) | 글자색을 더 진하게 바꿔 기준 충족 |

## 이 점검의 한계

- 시각장애인 등 실제 사용자 평가는 하지 않았습니다. 정식 품질인증은 전문가 3명 이상과 실제 사용자 평가를 거칩니다.
- 앞으로 글과 사진을 올리면 이 점검 결과도 달라질 수 있습니다.

## 앞으로 지킬 것

- 활동 사진을 올릴 때 사진 설명 한 줄을 함께 적기 (예: "어르신들과 김장 나눔을 하는 모습")
