# 사진·그림 저작권 원칙

홈페이지와 기관 문서에 넣는 사진·그림은 **저작권 문제가 없는 것만** 씁니다.
사람 얼굴이 나오는 사진의 초상권·개인정보는 [소식-문체가이드.md](소식-문체가이드.md) 5장을 따릅니다. 폰트는 [글꼴-원칙.md](글꼴-원칙.md)를 따릅니다.

## 써도 되는 것

| 종류 | 조건 |
|---|---|
| 기관 직원이 직접 찍은 사진 | 그대로 사용 |
| 함께한 기관·자원봉사자가 찍어 준 사진 | 홈페이지에 올려도 된다는 허락을 받고, 본문 끝에 `사진 제공: ○○` 로 출처를 적음 |
| 기관이 직접 만든 그림·포스터·안내문 | 그대로 사용(안에 넣은 그림·폰트도 이 원칙에 맞아야 함) |
| 공공누리 제1유형 자료 | 본문 끝에 출처(기관명·자료명)를 적음. 제2~4유형은 조건(상업 이용 금지·변경 금지)을 확인 |
| 무료 이미지 사이트의 사진·그림 | 사이트의 라이선스가 '상업적 이용 가능·출처 표시 불필요'인지 확인하고, 내려받은 주소를 Drive 게시글 폴더에 메모로 남김 |

## 쓰지 않는 것

- 인터넷 검색(네이버·구글 이미지 등)으로 찾은 사진·그림, 블로그·카페 사진
- **신문·방송 기사의 사진이나 기사 화면 캡처** — 언론사에 저작권이 있습니다. 언론 보도는 사진 없이 언론사 이름·기사 제목·기사 링크만 올립니다(업무관리 '언론 보도' 분류는 사진 칸이 없음).
- 다른 기관의 포스터·홍보물·로고(협약 등으로 허락받은 경우 제외)
- 캐릭터·연예인·만화 그림, 유료 이미지 사이트의 미리보기(워터마크) 그림
- 출처를 모르는 사진

## 업무관리에서 홈페이지 글을 쓸 때

1. 결재요청 전에 **「저작권 확인」** 에 체크해야 합니다(체크하지 않으면 결재요청이 되지 않음).
2. 첨부 PDF를 고르면 **따로 사야 하는 유료 글꼴(윤고딕·윤명조·산돌·폰트릭스 등)** 이 들어 있는지 자동으로 확인합니다.
   - 윈도우 기본 글꼴(돋움·굴림·바탕·맑은 고딕)과 한컴오피스 글꼴(HY 등)은 괜찮습니다.
   - 유료 글꼴이 나오면 다른 글꼴로 바꾼 뒤 PDF로 다시 저장해 올립니다.
   - 기관이 산 글꼴이거나 다른 기관에서 받은 공식 문서라 바꿀 수 없으면 예외 칸에 체크합니다. 결재자에게 예외로 표시됩니다.
3. 결재자는 사진 출처와 첨부 폰트 확인 결과를 보고 결재합니다.

## 문제가 생겼을 때

저작권자에게서 연락이 오면 업무관리 홈페이지 탭의 **「게시 내리기」** 로 그 글을 바로 내리고, 기관장에게 보고합니다.
