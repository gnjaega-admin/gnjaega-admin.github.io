# 첫 화면 팝업 올리기

팝업은 첫 화면(www.gnjaega.or.kr)을 열 때만 뜹니다. 내용은 `content/popups.json` 파일 하나에 적습니다.

## 적는 방법

```json
{
  "items": [
    {
      "id": "2026-chuseok",
      "title": "추석 연휴 휴무 안내",
      "text": "10월 3일부터 10월 9일까지 휴무입니다.\n긴급한 일은 02-573-7943으로 연락해 주세요.",
      "image": "content/uploads/2026-chuseok.png",
      "alt": "추석 연휴 휴무 안내 포스터. 10월 3일부터 9일까지 휴무",
      "link": "news.html#notice",
      "linkText": "공지사항 보기",
      "start": "2026-09-25",
      "end": "2026-10-09"
    }
  ]
}
```

| 칸 | 꼭 필요? | 설명 |
|---|---|---|
| id | 필수 | 영문·숫자·-·_ 로 된 이름 (예: 2026-chuseok) |
| title | 필수 | 팝업 제목 |
| text | 선택 | 본문. 줄바꿈은 `\n`, 문단 나눔은 `\n\n` |
| image | 선택 | 그림 파일. `content/uploads/` 안에 있는 파일만 됩니다 |
| alt | 그림이 있으면 필수 | 그림에 적힌 내용을 글로 (웹 접근성) |
| link, linkText | 선택 | 버튼으로 연결할 곳. 홈페이지 안 페이지(예: news.html#notice) 또는 https 주소 |
| start, end | 선택 | 게시 기간 (YYYY-MM-DD). 기간이 지나면 저절로 안 보입니다 |

- 한 번에 최대 5개까지 뜨고, 여러 개면 '이전 / 다음'으로 넘겨 봅니다.
- '오늘 하루 보지 않기'를 누르면 그 컴퓨터·휴대폰에서는 그날 하루 안 뜹니다.
- 포스터 그림만 올리지 말고, 중요한 내용(날짜, 연락처)은 `text`에도 적어 주세요.
- 팝업을 내리려면 `"items": []` 로 비우거나 `end` 날짜를 지난 날로 바꿉니다.
