# 글꼴(폰트) 원칙

기관 문서와 홈페이지에서 **따로 사야 하는 유료 글꼴은 쓰지 않습니다.**
무료 글꼴과, 기관이 정품으로 쓰는 프로그램(윈도우·한컴오피스)에 딸려 온 글꼴은 문서를 만들고 PDF로 보내는 데 써도 됩니다.

## 한눈에 보기

| 구분 | 예 | 쓸 수 있나 |
|---|---|---|
| 무료 글꼴 | 나눔고딕·나눔명조·나눔바른고딕, 프리텐다드, 본고딕·본명조(Noto Sans KR·Noto Serif KR), 함초롬 | 어디서나 사용 (권장) |
| 윈도우 기본 글꼴 | 돋움·굴림·바탕·궁서·맑은 고딕 | 문서 작성·출력·PDF 보내기에 사용 가능 |
| 한컴오피스에 딸린 글꼴 | HY 글꼴(HY헤드라인M 등), 한컴 돋움·바탕, 휴먼 글꼴, 한컴 윤고딕 | 한글 문서 작성·출력·PDF 보내기에 사용 가능 |
| 따로 사야 하는 유료 글꼴 | 윤디자인(윤고딕·윤명조), 산돌, 폰트릭스 등 | **사용 금지** (기관이 산 경우만 예외) |
| 출처를 모르는 글꼴 | 인터넷에서 내려받은 글꼴 파일 | **사용 금지** |

윈도우·한컴오피스 글꼴도 **글꼴 파일을 복사해 나눠 주거나, 홈페이지 웹폰트로 올리거나, 로고·판매용 디자인에 쓰는 것**은 프로그램 사용권 밖이라 하지 않습니다.

## 기관이 정해 둔 글꼴

| 어디에 | 글꼴 | 라이선스 |
|---|---|---|
| 홈페이지 화면 전체 | 프리텐다드(Pretendard) — `assets/fonts/PretendardVariable.woff2` | SIL 오픈 폰트 라이선스 1.1 (`assets/fonts/LICENSE-Pretendard.txt`) |
| 업무관리 화면 | 프리텐다드 | SIL 오픈 폰트 라이선스 1.1 |
| 공문 Word·PDF, AI 문서점검 결과, 주간 활동 문서 (업무관리가 자동으로 만드는 파일) | 나눔고딕 | SIL 오픈 폰트 라이선스 1.1 |
| 명조가 필요한 문서 | 나눔명조 | SIL 오픈 폰트 라이선스 1.1 |
| 공유 미리보기 그림(`assets/og-image.png`) | 프리텐다드 | SIL 오픈 폰트 라이선스 1.1 |

공문을 돋움 대신 나눔고딕으로 만드는 것은 품질 때문입니다. 공문 PDF는 구글 문서에서 만들어지는데, 돋움은 굵은 글자가 깨져 나오는 문제가 있었습니다.

## 첨부 파일을 만들 때 (홈페이지에 올리는 공지·공고·소식지 등)

1. 한글·워드에서 평소처럼 문서를 씁니다. 윈도우·한컴오피스 글꼴을 써도 됩니다.
2. 윤고딕·산돌처럼 따로 산 글꼴이 들어간 양식을 받았다면, 기관이 산 글꼴이 아닌 한 다른 글꼴로 바꿉니다.
3. 홈페이지와 외부 기관에 보낼 때는 **PDF로 저장해서** 올립니다.
   PDF에는 글꼴이 파일 안에 들어 있어 어느 기기에서나 같은 모양으로 보이고, 한글 프로그램이 없는 사람도 열 수 있습니다.
4. 업무관리 홈페이지 글쓰기에서 PDF를 고르면 **따로 사야 하는 유료 글꼴**이 들어 있는지 자동으로 확인합니다.
   유료 글꼴이 나오면 글꼴을 바꿔 다시 올리고, 기관이 산 글꼴이거나 다른 기관에서 받은 문서라 바꿀 수 없으면 예외 칸에 체크합니다.
