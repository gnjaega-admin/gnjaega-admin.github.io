# 글꼴(폰트) 원칙

기관이 만드는 모든 화면·문서·첨부 파일에는 **무료 글꼴만** 씁니다.
여기서 무료 글꼴은 개인·기관·상업 용도 모두 돈을 내지 않고 쓸 수 있고, 문서(PDF)에 넣어 배포해도 되는 글꼴입니다.

## 쓰는 글꼴

| 어디에 | 글꼴 | 라이선스 |
|---|---|---|
| 홈페이지 화면 전체 | 프리텐다드(Pretendard) — `assets/fonts/PretendardVariable.woff2` | SIL 오픈 폰트 라이선스 1.1 (`assets/fonts/LICENSE-Pretendard.txt`) |
| 업무관리 화면 | 프리텐다드 | SIL 오픈 폰트 라이선스 1.1 |
| 공문 Word·PDF, AI 문서점검 결과, 주간 활동 문서 (업무관리가 자동으로 만드는 파일) | 나눔고딕 | SIL 오픈 폰트 라이선스 1.1 |
| 명조가 필요한 문서 | 나눔명조 | SIL 오픈 폰트 라이선스 1.1 |
| 공유 미리보기 그림(`assets/og-image.png`) | 프리텐다드 | SIL 오픈 폰트 라이선스 1.1 |

그 밖에 써도 되는 무료 글꼴: 나눔 글꼴 모음(나눔스퀘어·나눔바른고딕 등), 본고딕·본명조(Noto Sans KR·Noto Serif KR), 프리텐다드.

## 쓰지 않는 글꼴

- **돋움, 굴림, 바탕, 궁서, 맑은 고딕** — 윈도우에 딸려 오는 글꼴로, 윈도우 라이선스 안에서만 쓸 수 있습니다.
- **HY 글꼴(HY헤드라인M, HY견고딕 등), 한컴 유료 글꼴, 윤고딕·산돌 등 유료 글꼴** — 한글 프로그램이나 다른 프로그램에 딸려 왔더라도 쓰지 않습니다.
- 출처나 라이선스를 모르는 글꼴.

## 첨부 파일을 만들 때 (홈페이지에 올리는 공지·공고·소식지 등)

1. 한글·워드에서 문서를 쓸 때 글꼴을 **나눔고딕 / 나눔명조**(또는 위 무료 글꼴)로 고릅니다.
   PC에 없으면 네이버 나눔글꼴 누리집(hangeul.naver.com)에서 무료로 내려받아 설치합니다.
2. 다른 사람이 만든 양식을 받아 쓸 때는 본문을 모두 선택해 글꼴을 무료 글꼴로 바꾼 뒤 저장합니다.
3. 홈페이지와 외부 기관에 보낼 때는 **PDF로 저장해서** 올립니다.
   PDF에는 글꼴이 파일 안에 들어 있어 어느 기기에서나 같은 모양으로 보이고, 한글 프로그램이 없는 사람도 열 수 있습니다.
4. 업무관리 공문은 결재가 끝나면 나눔고딕으로 Word·PDF가 자동으로 만들어지므로 따로 할 일이 없습니다.
   Word 파일은 받는 컴퓨터에 나눔고딕이 없으면 다른 글꼴로 보일 수 있으니, 밖으로 보낼 때는 PDF를 씁니다.

## 이전 홈페이지에서 옮긴 첨부 파일

이전 홈페이지(hanareum.or.kr)에서 옮긴 한글(hwp)·PDF 첨부 파일은 그때 만든 그대로 두었습니다.
같은 문서를 새로 올릴 일이 있으면 위 방법대로 무료 글꼴로 다시 만들어 PDF로 올립니다.
